# LP — Luis Pinzón

One-page site for LP (Luis Pinzón), house DJ in Atlanta.

Single self-contained `index.html` — photos embedded, no build step,
no dependencies. Fonts load from Google Fonts.

## Run locally

```bash
python3 -m http.server 8000
# open http://localhost:8000
```

or just open `index.html` in a browser.

## Deploy

Works as-is on any static host: GitHub Pages, Vercel, Netlify,
Cloudflare Pages — point it at the repo root.

Photos: Clip Play Media.
